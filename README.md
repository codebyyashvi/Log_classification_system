# Log Classification System

## Overview
The Log Classification System is designed to analyze and classify logs generated by various projects. It helps in identifying errors and serious issues that occur during the usage of the application, providing timely notifications to users and developers. This system utilizes different processing techniques, including BERT, LLM, and regex, to ensure accurate classification of logs.

## Features
- **Log Classification**: Classifies logs based on predefined categories.
- **Error Notification**: Alerts users when serious issues are detected in the logs.
- **Multiple Processing Techniques**: Utilizes BERT, LLM, and regex for effective log processing.

## Project Structure
```
Log_classification_system/
├── classify.py              # Main classification script
├── processor_bert.py        # BERT-based log processor
├── processor_llm.py         # LLM-based log processor
├── processor_regex.py       # Regex-based log processor
├── requirements.txt         # Project dependencies
├── __pycache__/             # Compiled Python files
├── models/                  # Directory for model files
│   └── log_classifier.joblib # Trained log classifier model
├── resources/               # Directory for resources
│   ├── output.csv           # Output file for classified logs
│   └── test.csv             # Test file for validation
└── training/                # Directory for training scripts
    └── training.ipynb       # Jupyter notebook for training the model
    └── dataset/             # Directory for datasets
        └── synthetic_logs.csv # Sample dataset for training
```

## Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Log_classification_system
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
1. **Run the classification script**:
   ```bash
   python classify.py
   ```
2. **Run the server (development)**:
   ```bash
   uvicorn server:app --reload
   ```
   This will start the application on localhost (default: `http://127.0.0.1:8000`). To change host/port, use e.g. `uvicorn server:app --reload --host 0.0.0.0 --port 8000`.
3. **Train the model** (if needed):
   Open the `training/training.ipynb` Jupyter notebook and run the cells to train the log classifier.
